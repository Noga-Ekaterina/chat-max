# Chat MAX

Веб-приложение для обмена текстовыми сообщениями в MAX через GREEN-API. Пользователь подключает свой инстанс, находит получателя по номеру телефона и открывает чат. 

## Возможности

- Подключение по `idInstance` и `apiTokenInstance` с проверкой состояния инстанса.
- Проверка аккаунта MAX по номеру телефона России или Беларуси.
- Отправка текстовых сообщений длиной до 4000 символов.
- Получение входящих текстовых сообщений через опрос очереди уведомлений.
- Отображение времени сообщений и автоматическая прокрутка переписки.
- Адаптивный интерфейс на русском языке.

## Технологии

React 19, TypeScript 6, Vite 8, Tailwind CSS 4. HTTP-запросы выполняются через встроенный `fetch`, проверка кода — через Oxlint.

## Запуск

Понадобятся Node.js версии `20.19+` в ветке 20 либо `22.12+`, npm и авторизованный инстанс GREEN-API для MAX. Подготовьте `idInstance`, `apiTokenInstance` и базовый адрес API своего инстанса.

1. Установите зависимости из корня проекта:

   ```sh
   npm ci
   ```

2. Создайте или отредактируйте `.env` в корне проекта:

   ```dotenv
   VITE_GREEN_API_URL=
   ```

   Укажите адрес API своего инстанса без завершающего `/`.

3. Запустите сервер разработки:

   ```sh
   npm run dev
   ```

4. Откройте адрес из терминала; по умолчанию это `http://localhost:5173`.

После изменения `.env` перезапустите сервер разработки. При сборке адрес API встраивается в приложение, поэтому для его изменения потребуется повторная сборка.

## Использование

1. Введите `idInstance` и `apiTokenInstance`, затем нажмите «Войти в чат». Инстанс должен находиться в состоянии `authorized`.
2. Укажите номер получателя: `+7` и ещё 10 цифр либо `+375` и ещё 9 цифр. Пробелы, скобки и дефисы допускаются.
3. Нажмите «Выбрать получателя». После успешной проверки откроется чат.
4. Напишите сообщение и отправьте его кнопкой со стрелкой или клавишей Enter. Входящие текстовые сообщения собеседника добавляются автоматически во время открытого чата.
5. Для выбора другого получателя нажмите стрелку назад в заголовке чата.

| `npm run build` | Проверка TypeScript и сборка в `dist/` |

Для просмотра сборки выполните `npm run build`, затем `npm run preview`. Для публикации разместите содержимое `dist/` на статическом хостинге.

## Работа с API и ограничения

Приложение использует методы `getStateInstance`, `checkAccount`, `sendMessage`, `receiveNotification` и `deleteNotification` по пути `/waInstance{idInstance}/…`.

- Данные подключения хранятся в памяти страницы и сбрасываются при перезагрузке. Приложение не записывает их в `localStorage` или `sessionStorage`.
- История хранится только в состоянии открытого чата. При возврате к выбору получателя или перезагрузке она очищается; загрузка прошлой переписки не реализована.
- Поддерживаются текстовые сообщения. Отправка файлов, групповые чаты и статусы доставки не реализованы.
- Опрос уведомлений работает только при открытом чате. Отображаются входящие текстовые сообщения выбранного получателя, но из очереди удаляются все полученные уведомления, включая события других чатов.
- Входящие сообщения должны поступать в очередь уведомлений инстанса GREEN-API. Если ответы не появляются, проверьте настройки уведомлений и состояние инстанса.
